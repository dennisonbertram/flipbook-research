# Research Programs

This folder holds repeatable research loops: what is fixed, what can change, how experiments are scored, and when a result is kept or discarded.

## Programs

- `track-a-autoresearch-program.md` adapts Karpathy's `autoresearch` pattern to Track A model-layer work.
- `track-d-general-neural-canvas.md` defines the path from one-page overfit renderers to an amortized held-out-page neural canvas compiler.
