Can Generated Pages Come Alive?

We explored a simple dream: take an AI-generated page, like a field guide or illustrated explainer, and make it feel alive without losing the page itself.

The goal

We wanted something between a webpage, a book page, and a tiny film.

Imagine a generated travel guide where the map breathes slightly, the illustration has atmosphere, and the page responds as you move through it. Or a generated lesson where a diagram subtly unfolds, but the labels and explanation stay readable.

The hard part is that pages are not just pictures. A page contains words, diagrams, margins, hierarchy, and meaning. If a model makes a beautiful animation but rewrites the text, the page is gone.

The headline lesson: today’s video models are great at making motion and atmosphere. They are not yet trustworthy at preserving a page.

Examples from the work

The most interesting runs were not perfect. They showed the shape of the problem.

Promising

The field-guide page became cinematic.

This run had the feeling we were chasing: a generated page with real atmosphere and model-made motion. It also showed the danger. The model wanted to turn the page into a scene, adding large foreground shapes that were not in the original.

Good for: illustration-rich pages. Risk: the model invents new objects and changes the composition.

Interesting

The explainer page stayed recognizable, but not stable.

This was one of the more interesting generated-video results. The model kept the overall page identity, but it still zoomed, softened, and distorted parts of the diagram and text.

Good for: seeing what real generated pixels can add. Risk: words and diagrams become approximate.

Fast path

A small page engine could make subtle motion quickly.

These experiments were less cinematic, but they mattered. They suggested that a lightweight animation layer can make a page feel alive without handing the whole page to a video model.

Good for: instant page liveness. Risk: it can look like drift or shimmer rather than true layout change.

Closest to the dream

The page actually tried to re-layout.

This was one of the most revealing failures. It looked like the page was trying to become a new arrangement, which is much closer to the original dream. But the text broke down.

Good for: showing the real research direction. Risk: meaning gets lost before the layout gets good.

What we learned

The page has to stay in charge.

01

A page is not a normal image.

If a generated landscape changes a tree, it may still be fine. If a generated page changes a word, label, or diagram, it may no longer mean the same thing.

02

Video models want to be cinematic.

That is a strength when the page is mostly illustration. It is a problem when the page contains information that must remain exact.

03

Fast controlled motion is already useful.

A page can feel more alive through small controlled movement: gentle lighting, layered animation, and motion in parts of the page that can safely move.

04

True re-layout needs understanding.

The next step is not just “better video.” The system needs to know what is text, what is a diagram, what can move, and what must stay fixed.

What is possible now

A real product could combine two layers.

First, show the page immediately.

Start with a high-quality generated page. Add controlled motion that preserves the words, layout, and important visual structure.

Then, try a richer generated clip in the background.

For pages that can tolerate it, ask a video model to create a more atmospheric version. Only use it if it still looks like the same page.

For true page transformation, build a page-aware system.

The long-term path is a model that understands the page as layers of meaning, not just pixels. That is the route toward genuine re-layout.

Where we landed

We did not solve living pages, but we found the right shape of the problem.

The promising direction is not to ask a video model to remember a page perfectly. It is to keep a page representation as the source reference, animate what can safely move, and use generated video as an optional layer when it adds something beautiful without breaking the meaning.
