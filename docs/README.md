# Flipbook Research Docs

This directory keeps the research organized around testable questions. The current goal is to understand how to produce a Flipbook-like live visual browser where a strong static image becomes a low-latency animated stream.

## Map

- `poc/benchmark-target.md` defines the shared performance gate for any proof of concept.
- `poc/track-a-full-ltx.md` documents the full-frame LTX image-to-video benchmark path.
- `poc/track-b-codec-style-animation.md` documents the static-image-plus-motion path.
- `poc/track-c-neural-canvas-renderer.md` documents the persistent neural canvas renderer path.
- `research/track-d-general-neural-canvas.md` defines the path from one-page overfit renderer experiments to a general amortized neural canvas model.

## Current Hypothesis

The first still image is generated by a separate high-quality image system. The live video layer likely starts from that still image, then either generates full video segments or animates only selected regions while preserving text-heavy areas.

The first proof-of-concept gate is:

```text
33 frames generated + decoded + encoded in <= 1.3s
```

That target is intentionally hard. It tells us whether a system can plausibly stream at `24fps` with minimal buffering.
